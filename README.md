# 🌤️ Weather Dashboard

A clean and simple weather dashboard built with Python & Flask.

---

## 🚀 Live Demo

▶️ **[Try it on Replit](https://replit.com/@kaungmyatpaing1/weather-dashboard)**

---

## ✨ Features
- Search weather by city name
- Shows temperature, humidity, wind speed
- Clean modern UI with glassmorphism design
- Real-time data from OpenWeatherMap API

---

## 🛠️ Tech Stack
| Technology | Usage |
|---|---|
| Python 3 | Main language |
| Flask | Web framework |
| OpenWeatherMap API | Weather data |
| HTML / CSS / JavaScript | Frontend |

---

## ⚙️ Setup & Run

```bash
# 1. Clone the repo
git clone https://github.com/KAUNGMYATPAINGTHAR-dev/weather-dashboard.git

# 2. Move into the folder
cd weather-dashboard

# 3. Install dependencies
pip install -r requirements.txt

# 4. Add your API key
echo "OPENWEATHER_API_KEY=your_api_key" > .env

# 5. Run the app
python app.py
```
